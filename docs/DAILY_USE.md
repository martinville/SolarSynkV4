# Daily use

1. Open **Overview** to see inverter count, V4 entity count, available inverter count, add-on uptime, cloud and MQTT status, and the last cloud refresh. Expand an inverter card to see its entities, stable MQTT unique IDs, units and values. Home Assistant may assign different visible entity IDs.
2. Cloud data is sent to MQTT as soon as a fetch finishes. To request another fetch immediately, select **Send all data to MQTT** on Overview. This fetches current cloud telemetry and supported settings, republishes V4 discovery, and sends their states to MQTT. The result appears after you reload Overview. A successful cloud response can still contain old inverter data.
3. Open **Inverter Settings** to change a supported setting. Edit one or more values and select the single **Save changes** button at the bottom. The same 104 controls appear as Home Assistant MQTT number, switch, or text entities (schedule times use HH:MM) when the cloud reports those fields. `peakAndVallery` is the **Use timer** switch. Grid and parallel topology controls are excluded.
4. Wait for the result. While the change is pending, its requested value stays visible even if the cloud still reports the old value. **Activity** records cloud fetches, MQTT connection and discovery events, telemetry sends, and confirmed, rejected, or unconfirmed setting changes. Confirmation means a later cloud settings read showed the value; it does not prove the physical inverter applied it.
5. Open **Setup → Select Inverters** to select or deselect devices in the popup. The saved list and your selection survive restarts. Use **Refresh inverter list** only when the cloud account gains a new device. Deselecting removes V4 MQTT discovery for that device and stops polling it. Home Assistant's recorder history is not deleted.
6. Open **Setup → Cloud Setup** to update the cloud account or polling. Open **Setup → Setup MQTT** to test or change broker details in the popup. Saved passwords can be left blank to keep them.

Home Assistant's Developer Tools **Set state** changes only Home Assistant's displayed state; it does not send an inverter command. Use the discovered entity's normal control, the Home Assistant actions `number.set_value`, `switch.turn_on` / `switch.turn_off`, or `text.set_value` for schedule times, or the V4 **Inverter Settings** page.
